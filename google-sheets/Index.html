Atomic Quiz API

API para gestión de usuarios y alumnos

POST /registrarAlumnoConUsuario

Registra alumno y crea usuario simultáneamente. Parámetros: nombre, apellido, carrera, area, celular, dni, email, username, password

POST /createUser

Crea un usuario. Parámetros: username, password, role, nombre

GET /login?username=xxx&password=yyy

Inicia sesión. Retorna datos del usuario

GET /getAlumnos

Obtiene todos los alumnos

GET /getUsuarios

Obtiene todos los usuarios
